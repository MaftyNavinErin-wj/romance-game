**规则**:User 说"继续" / "启动" / 同义触发 sprint batch 时,CC **直接选**下一个最合理 batch + 进入 mini scout,**不要**列 2-3 候选清单等 user 拍板。

**Why**:user 已 streamline workflow(batch-6 启动期 sprint 节奏成熟). batch 选择是 CC 范围内 routine call(基于 memory next 标 + 同源系列连贯性 + walkthrough 优先级). 列候选+等 yes 加无价值 round trip.

**How to apply**:
- 选择信号明显(memory next / 同源系列正在跑 / 优先级清楚)→ 直接选 + 开 mini scout
- mini scout 报告 + 决策点 approve 流程**仍保留**(原则 #1 设计决策必 approve 不变 — 这是 fix 设计层,不是 batch 选择层)
- batch 选择真模糊(多个等价 / user 上下文转向 / 跨大类 sprint vs phase 4 vs 跨链)→ 一句话简短 confirm,不要长候选表

**例外仍 confirm**:
- user 明显在 explore("我们能做什么?" / "推荐?")
- batch 框架切换(P15c 系列收尾后切 D-117c 新模式 — 这种简短一句话提一下,不需选项表)
