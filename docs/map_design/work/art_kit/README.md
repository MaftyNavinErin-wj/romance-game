# Stage 2 Art Kit Reference Workspace

This directory stores Stage 2 art kit reference images for the national map workflow.

Status:

- Reference-only.
- Not runtime assets.
- Not final map art.
- Not promoted to `assets/maps/`.
- Not used as city, hex, road, or river data authority.

Later stages may use these images only as style, texture, and element-reference material. Any production terrain, riverbank, farmland, forest, mountain, road, pass, city, or fort asset still needs a separate review and producer approval before promotion.
